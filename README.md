# DaVinci Match Helper

Працездатний веб-додаток українською мовою для підключення власного Telegram акаунта та напівавтоматичного пошуку збігів в анкетах DaVinci/Дайвінчик.

## Що вміє

- приймає Telegram `API ID`, `API Hash`, номер телефону, код підтвердження та 2FA пароль, якщо він увімкнений;
- зберігає MTProto-сесію локально в `data/sessions.json`, щоб не вводити код при кожному оновленні сторінки;
- читає останнє повідомлення з вибраного Telegram-бота, за замовчуванням `@leomatchbot`;
- показує фото та відео з анкети прямо на сайті, якщо медіа прикріплене до останнього повідомлення бота;
- рахує відсоток збігу за інтересами користувача з нечітким пошуком: різні регістри, апострофи, базові українські відмінки та схожі написання;
- додає AI-бонус до відсотка, якщо в анкеті знайдено виконавця/гру/обʼєкт, жанр або категорія яких збігається з інтересами чи ключовими словами;
- підтримує переклади поширених ключових слів українською, англійською та російською;
- опційно аналізує текст і фото через OpenAI, якщо задано `OPENAI_API_KEY`;
- зупиняє пошук, якщо відсоток збігу досяг порогу або знайдені ключові слова;
- якщо збіг слабкий, надсилає в бот команду пролистування `👎`;
- після зупинки дає ручні кнопки: лайкнути, пролистати або написати повідомлення.

> Додаток працює тільки з акаунтом, до якого користувач сам надає доступ. Не передавайте API Hash, телефон, код або файл `data/sessions.json` стороннім людям.

## Як отримати доступ Telegram

1. Відкрийте <https://my.telegram.org/apps>.
2. Увійдіть у свій Telegram акаунт.
3. Створіть застосунок і скопіюйте `api_id` та `api_hash`.
4. Вставте ці значення у форму «Доступ до Telegram» у веб-додатку.
5. Введіть номер телефону, код із Telegram і 2FA пароль, якщо Telegram його попросить.

## Запуск

```bash
npm install
# опційно для AI-аналізу фото й тексту через OpenAI:
# export OPENAI_API_KEY=your_key
# export OPENAI_MODEL=gpt-5.6
npm start
```

Після запуску відкрийте <http://localhost:3000>.

## Важливо про роботу з ботом

DaVinci може змінювати тексти кнопок, формат анкет і спосіб надсилання медіа. У цій версії слабкий збіг автоматично пролистується через надсилання `👎`, а ручні дії надсилають `❤️`, `👎` або відкривають поле для власного повідомлення. Якщо ваш бот очікує інші команди, змініть `actionMap` у `server.js`. Медіа більше 20 МБ не вбудовується у сторінку, щоб не перевантажувати браузер. Нечіткий пошук використовує нормалізацію, просте обрізання українських закінчень і Levenshtein-подібність, тому може знаходити близькі слова без повного словника української мови. Без `OPENAI_API_KEY` працює локальний словниковий AI-шар для частини популярних виконавців, ігор, жанрів і перекладів; з ключем OpenAI додатково аналізуються фото та довільні текстові згадки.
